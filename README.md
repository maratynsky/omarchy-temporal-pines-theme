# Temporal Pines

A dark Omarchy theme inspired by *Back to the Future*: midnight navy, electric cyan, hot magenta, and amber highlights.

The name nods to Twin Pines Mall becoming Lone Pine Mall after Marty changes the past.

![Temporal Pines — Neon Drift](backgrounds/01-neon-drift.png)

## Install

```bash
omarchy theme install https://github.com/maratynsky/omarchy-temporal-pines-theme
omarchy theme set temporal-pines
```

Omarchy generates terminal and application colors from `colors.toml`. The theme uses the standard templates for Kitty, Ghostty, Alacritty, Foot, and other supported applications.

Cycle wallpapers with `omarchy theme bg next`.

## Optional terminal styling

The [extras](extras/README.md) provide a magenta Starship prompt, cyan folders, and amber dates, sizes, and Git status. Omarchy does not install these extras automatically.

## Work on the theme

```bash
git clone https://github.com/maratynsky/omarchy-temporal-pines-theme.git
cd omarchy-temporal-pines-theme
# Edit colors.toml or replace images in backgrounds/.
make install
```

`make install` copies the palette and wallpapers into your user theme directory and applies Temporal Pines. Make a backup first if that directory contains your own edits. It does not install the optional terminal styling.

The palette is the source of truth; terminal configuration files are generated by Omarchy rather than committed here.
